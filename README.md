## 🔍 About claude-dnd

claude-dnd is a plugin designed for Claude Code. It acts as an engine for playing Dungeons & Dragons 5th Edition (D&D 5e). This tool helps automate game elements like dice rolls, player stats, and game events. It aims to make your tabletop RPG sessions smoother, whether you are alone or with a group.

You don’t need to know programming to use claude-dnd. This guide will help you download, install, and start it on your Windows computer.
